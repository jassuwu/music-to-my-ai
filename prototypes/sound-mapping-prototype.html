What should a streaming response sound like?

Text from an LLM does not arrive one tidy token at a time — it lands in bursts, with pauses while the model thinks. This page fakes that arrival exactly and plays five candidate mappings from arriving text to music, so the question "which of these is actually delightful rather than chaotic?" can be settled by ear instead of on paper. Pick a mapping, run a stream, then run the same stream under a different mapping and compare.
